# Getting Started
[AnuPpuccin](https://github.com/AnubisNekhet/AnuPpuccin) is a Catppuccin theme for Obsidian. Its development seems to have stopped, which makes this theme -- and therefore my styling -- stable.

The structure is rather simple:
- `theme_variables.css` defines all color schemes, UI element colors and tweaks, etc.
- `theme_core.css` applies a priori defined colors to various elements.
- `anuppuccin_theme.json` is the theme's settings to import in Style Settings.
- The rest are specialized styles for mimicking a liquid glass sidebar and monochromatic folder colors.
